# M3U 直播源

填一个 m3u / m3u8 播放列表地址，按分组浏览频道并直接播放。

**添加服务器 → 插件源 → M3U 直播源**，把播放列表地址填进去就行。

## 它演示了什么

一个数据源插件只需要三个函数：

```js
ctx.sources.register('playlist', {
  async listDir(dirId, server)                 { /* 浏览 */ },
  async search(query, server)                  { /* 搜索 */ },
  async resolvePlay(entry, qualityId, server)  { /* 给出能播的地址 */ }
})
```

写完这三个，浏览页 / 搜索 / 播放 / 续播 / 收藏全都是白拿的，不用新增任何页面。

## 两个坑

**直播地址常常没有扩展名**，宿主的扩展名表认不出来，所以条目必须显式写
`isVideo: true`，否则频道会被当成普通文件、根本不给播。

**出网白名单只有 `$sourceServer`**。它在运行时展开成用户填的那个播放列表地址的
origin —— 通用插件在发布时不可能知道用户的列表放在哪，所以只能靠这个令牌。
频道的播放地址通常在别的域名上，但那是宿主播放器直接去取的，不经过插件，不受限制。
