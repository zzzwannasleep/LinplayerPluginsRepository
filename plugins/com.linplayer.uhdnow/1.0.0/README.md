# UHDNow 助手

UHDNow 用户的三合一工具。v1 时代这是三个各自独立的插件，同一套网站账密要填三遍。

| 在哪 | 干什么 |
|---|---|
| 首页 | 剩余流量 / 总流量（只在当前服务器是 UHDNow 时出现） |
| 侧栏「UHDNow 助手」 | 求片 / 追新、我的求片、全部求片（可投票）、线路测速 |
| 设置 | 网站账号，只填一次，三块功能共用 |

## 账号为什么要自己填

v1 用的是 `emby.credentials` 权限，直接问宿主要你的登录密码。v2 把这个权限整个
删掉了：宿主不再持久化明文密码。插件想要账密就自己弹表单、自己存（每个插件的
storage 互相隔离，别的插件读不到）。

顺带也更准确 —— UHDNow 的**网站**账号本来就可能和 Emby 账号不是一个。

## 测速会消耗流量

测速是真的下载 32 / 64 / 100 MiB 数据，走你自己的账户额度。

和 v1 相比这里有个能力回退：v2 的 `ctx.http` 没有流式进度回调，所以测速过程中
只能显示一个「正在测速」，没有实时百分比，测完一次性给平均速度。
