# 沙箱界面示例

声明式界面画不出来的东西（图表、画布、复杂交互），用插件自带的网页画。

`main.js` 里几乎没有代码 —— 界面在 `view/index.html`，由 manifest 的
`contributes.sandboxViews` 声明，宿主用一个**独立 origin 的 iframe** 加载它。

## 为什么必须隔离

App 主窗口的 JS 上下文里有 Tauri 的 `invoke`。插件代码要是能进去，就等于拿到宿主
的全部命令，整套权限模型直接作废。所以逃生舱里的网页**拿不到 `ctx`，也拿不到 App
的任何接口** —— 它就是一张普通网页，自己写 CSS，自己管深浅色。

## 怎么分工

| 想干的事 | 写在哪 |
|---|---|
| 调 `ctx.http` / `ctx.storage` / 提供数据源 | `main.js` |
| 画声明式界面画不出来的东西 | `view/` 里的网页 |

两边要通信的话，目前只能靠 `main.js` 把数据先写进 storage、网页那边自己重新取 ——
逃生舱是故意做窄的。
