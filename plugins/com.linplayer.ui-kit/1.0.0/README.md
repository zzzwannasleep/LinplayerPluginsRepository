# 界面块速查

插件不写 HTML，只交一棵 JSON 描述树，宿主用自己的组件去画。好处是同一份代码在
电脑 / 手机 / 电视上都长得像原生界面，遥控器焦点白拿；代价是只能用规定的这些块。

启用后打开侧栏的「界面块速查」，每一块下面都贴着生成它的 JSON，直接抄。
「设置」页里另有 5 个弹窗（提示 / 确认 / 表单 / 选择 / 进度）可以点着试。

## 上限

树深 12 层、总节点 400 个、每层子节点 100 个。超了会被**截断**，不报错。

## 最容易写错的两处

- 输入类节点的键是 `id`（不是 `key`），初始值是 `value`（不是 `default`）
- 图片地址只认 `https://`、`data:image/`、`lpplugin://`，别的会被丢掉

真放不下的界面走 `sandboxViews` 逃生舱，见「沙箱界面示例」。
