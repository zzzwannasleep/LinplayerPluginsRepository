# CF 优选反代

为走 **Cloudflare** 的服务器线路，从你**本地**实测挑出最快的 CF 边缘 IP，并通过
**本地反代**把该服务器的线路改写到这个优选 IP。比公共优选 IP 更贴合你的网络环境，
能明显改善起播慢、卡顿。支持**定时测速**，全天候保速。

## 原理

Cloudflare 是 anycast 网络，按 **SNI + Host** 调度回源——无论你连到哪个 CF 边缘
IP，只要 TLS SNI / HTTP Host 仍是你的域名，就能正确回到源站。所以：

1. 从 Cloudflare 公开 IP 段随机抽样一批边缘 IP；
2. 对它们做 **TCP 握手延迟 + 丢包** 测试并排序；
3. 对延迟最优的若干个做 **HTTPS 下载测速**（SNI = 测速域名）；
4. 选出最快的 IP，启动一个监听在 `127.0.0.1` 的**本地反代**，上游 TLS 连到这个
   优选 IP（SNI/Host 仍是你的真实域名），并把该服务器的线路地址改写到本地反代。

这样 App 的接口请求与 mpv 取流都自动走优选 IP，**与播放器无关**。

> 下载测速用的是独立的测速文件（默认为社区托管在 Cloudflare R2 上的 100MB 文件，
> 走 CF 边缘、出站免费），**不会拉你的 Emby 服务器**。你也可以在面板里换成自己
> R2/CDN 上的测速文件，或任意公共 CF 测速链接（下载测速会自动跟随重定向）。
>
> 另外，延迟之外还有一道 **HTTP 校验**：用 `https://<你的域名>/cdn-cgi/trace`
> （由 CF 边缘应答、不回源、不加载 Emby）确认候选 IP 真能为你的域名服务，剔除
> 「TCP 通但 HTTP 死」的 IP；绝不会把没通过校验的 IP 拿来反代。

## 使用

1. 在「设置 → 插件」启用本插件并授予权限。
2. 打开本插件的设置（或侧边栏入口）→ 进入「CF 优选反代」面板。
3. 选中要加速的服务器，点 **测速并反代**，等进度跑完即生效。
4. 需要全天候保速，打开该服务器的 **定时测速** 开关并选择间隔。
5. 想恢复直连，点 **关闭反代** 即可。

## 权限说明

- `cfproxy`：执行 CF 优选测速，并启用/关闭本地反代（仅把线路指向 `127.0.0.1`
  本地反代，不外发任何凭据）。
- `ui`：弹出提示。
- `extensions`：注册设置页 / 侧边栏入口。

## 平台

- ✅ PC（Windows / macOS / Linux）：完整可视化面板 + 实时测速进度。
- ✅ 移动端（同一引擎，面板可用）。
- ✅ TV：遥控器友好的原生面板（设置 → 网络 → CF 优选反代），同一套优选/反代引擎。

## 优选协议（IPv4 / IPv6）

面板顶部「优选协议」可选 **自动 / 仅 IPv4 / 仅 IPv6 / 双栈**：

- **自动**（默认）：探测本机是否有 IPv6，有则双栈一起测，无则仅 IPv4。
- IPv6 命中率天然低于 IPv4（地址空间大、活跃边缘稀疏），不可达候选会在测速阶段
  直接淘汰；仅当你本机/服务器都支持 IPv6 时才有意义。

## 已知限制

- 反代不转发 WebSocket（Emby 的实时通知用，**不影响播放**）。
- 若服务器线路本就不走 Cloudflare，优选无意义。
